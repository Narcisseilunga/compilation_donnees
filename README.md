# compilation_donnees

## Blender apartment generator

This repository includes a Blender Python script that generates an apartment building:

- R+1 or R+2 (configurable floors)
- Two apartments per level
- Each apartment with 3 bedrooms
- Doors and windows with glass panes

### Usage

1. Open Blender.
2. Go to the **Scripting** workspace.
3. Open `blender_apartment_generator.py`.
4. Adjust the `CONFIG` dictionary if needed (floors, sizes, etc.).
5. Click **Run Script**.

The scene will be cleared and replaced by the generated building.
